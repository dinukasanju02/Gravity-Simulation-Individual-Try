# Gravity Simulation 3D

A complete Python + Panda3D OOP project built from scratch.

## Main features
- Fully 3D Sun, 8 planets and Earth's Moon
- 3D Saturn rings
- 3D star field
- Newtonian N-body gravity
- 3D orbital motion
- 3D orbital trails
- Dynamic 3D spacetime-curvature mesh
- Free orbit/zoom camera
- Purple project intro screen
- HUD and keyboard controls
- OOP: abstraction, encapsulation, inheritance and polymorphism

## Installation

Open Command Prompt in this folder:

```bash
pip install -r requirements.txt
```

Then:

```bash
python main.py
```

## Controls

- Left mouse drag = rotate camera
- Mouse wheel = zoom
- W / S = move focus forward/back
- A / D = move focus left/right
- Q / E = move focus down/up
- SPACE = pause/resume
- M = show/hide spacetime mesh
- T = show/hide orbital trails
- R = reset to initial state
- ESC = exit
